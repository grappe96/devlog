# 두 번째 게시글 shadcn/ui를 활용한 UI 구축 경험을 공유합니다. ## shadcn/ui란? shadcn/ui는 복사해서 사용할 수 있는 재사용 가능한 컴포넌트 모음입니다. ## 장점 1. **커스터마이징이 쉬움**: 컴포넌트를 직접 수정할 수 있습니다. 2. **TypeScript 지원**: 완벽한 타입 안정성을 제공합니다. 3. **Tailwind CSS 기반**: 일관된 스타일링이 가능합니다. ## 사용 예시 이 블로그에서는 Button, Card 등의 컴포넌트를 사용하고 있습니다.
