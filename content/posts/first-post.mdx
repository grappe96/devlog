# 첫 번째 게시글

안녕하세요! 이것은 첫 번째 게시글입니다.

## 소개

이 블로그는 Next.js App Router와 TypeScript를 사용하여 구축되었습니다.

## 주요 기능

- 정적 사이트 생성 (SSG)
- Markdown/MDX 지원
- 반응형 디자인
- GitHub Pages 배포
