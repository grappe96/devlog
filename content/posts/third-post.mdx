# 세 번째 게시글

GitHub Pages로 Next.js 정적 사이트를 배포하는 방법을 설명합니다.

## 배포 과정

1. Next.js 프로젝트를 빌드합니다.
2. `output: 'export'` 설정으로 정적 파일을 생성합니다.
3. `gh-pages`를 사용하여 배포합니다.

## 주의사항

- `basePath` 설정이 중요합니다.
- CSS 파일 경로 문제를 주의해야 합니다.

## 결론

GitHub Pages는 무료로 정적 사이트를 호스팅할 수 있는 좋은 방법입니다.
